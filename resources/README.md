# Resources

Short, standalone explainers for background concepts this course relies on
but doesn't have dedicated lecture time for. Unlike weekly lecture/lab
material, these aren't tied to a specific week — read them whenever a gap
comes up, or whenever a lab/lecture links to one.

- [**Intro to Git**](GIT.md) — what version control actually does, the
  working-directory → staging → local repo → remote workflow, and a
  cheatsheet of every Git command used this semester.
- [**Markdown Cheatsheet**](MARKDOWN.md) — basic Markdown syntax for
  writing `README.md`/`AI_USAGE.md` files, R Markdown/Jupyter text cells,
  and anything else that renders on GitHub.

More pages will be added here over the semester as gaps come up.
