# Applied Computing in Health Data Science

Companion repository for **PUBH 6854 / PUBH 4201**, Fall 2026 (Matthew Bendall, GWU Milken Institute School of Public Health).

Application of computational paradigms in biomedical sciences and health informatics: computing environments, reproducible research, data management, and analysis workflows using R, Python, and generative AI.

## Repository structure

- `lectures/` — one folder per week (`week01`…`week15`), slides and in-class materials
- `labs/` — the 5 graded lab assignments, one folder each
- `project/` — final project requirements, proposal template, rubrics, example project ideas
- `environment/` — environment/dependency files (conda, renv, Docker) for the course
- `data/` — `raw/` (input datasets used in labs/lectures) and `processed/`
- `resources/` — supplemental readings and slide assets

## Course structure

15-week semester in 3 modules:

1. **Weeks 1–5** — Computing Environments, Reproducibility, and Data Wrangling
2. **Weeks 6–10** — Programming, Databases, and Scientific Visualization
3. **Weeks 11–15** — Generative AI, Prompt Engineering, and Advanced Workflows

See [`SCHEDULE.md`](SCHEDULE.md) for the full session-by-session schedule and [`GRADING_AND_POLICIES.md`](GRADING_AND_POLICIES.md) for grading breakdown, evaluation criteria, and class policies (collaboration, generative AI use, late work, etc.). See `project/requirements.md` for final project details and the syllabus for the authoritative, official version of policies and grading.
