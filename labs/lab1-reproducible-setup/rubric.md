# Lab 1 Rubric (9% of final grade)

| Criterion | Points | Notes |
|---|---|---|
| Project structure | 15 | Matches required layout (incl. `.gitignore`), sensible organization, real GitHub repo (not a zip) |
| Environment file works | 30 | Delete the environment, recreate it from nothing but the file, confirm the script gives the same output — the exact test from Week 2's practical |
| Container (grad: required / undergrad: bonus) | 20 | `docker build` + `docker run` gives the same output as running natively; grad students docked here if missing |
| AI_USAGE.md | 20 | Specific — names the actual error/question, whether "what does this mean" was asked before "how do I fix it," and how the fix was verified before running. Not a vague blanket statement |
| README quality | 15 | A stranger could follow it |
| Graduate addendum (grad only) | +10 (replaces container weight if undergrad opts in) | Comparison is substantive, not superficial |

**Total: 100 pts → scaled to 9% of course grade.**
