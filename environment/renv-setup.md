# R environment (renv)

This repo does not ship a committed `renv.lock` because lockfiles are
generated by actually running `renv::snapshot()` in R against the exact
package set a script/notebook uses — committing one blind (without R
available to run it) risks a lockfile that doesn't match reality, which is
worse than no lockfile. Once lecture/lab R code exists, run the block below
from the repo root to generate it for real.

## Initial setup (run once, in R, from the repo root)

```r
install.packages("renv")
renv::init()

install.packages(c(
  "tidyverse",   # dplyr, ggplot2, readr, tidyr, etc.
  "rmarkdown",
  "knitr",
  "DBI",
  "RSQLite",
  "duckdb",
  "jsonlite",
  "renv"
))

renv::snapshot()
```

This creates `renv.lock` and an `renv/` folder (already gitignored except
for `renv/activate.R` and `renv.lock`, per renv convention — confirm
`.gitignore` matches renv's own generated `.gitignore` after `renv::init()`).

## For students (Lab 1)

```r
install.packages("renv")
renv::restore()   # reads renv.lock, installs exact package versions
```
